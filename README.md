# Анализатор качества репозиториев (Rails)

[![hexlet-check](https://github.com/DimaArsyonov/rails-developer-project-66/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/DimaArsyonov/rails-developer-project-66/actions)
[![CI](https://github.com/DimaArsyonov/rails-developer-project-66/actions/workflows/ci.yml/badge.svg)](https://github.com/DimaArsyonov/rails-developer-project-66/actions/workflows/ci.yml)

Проект, который помогает автоматически следить за качеством репозиториев на гитхабе. Он отслеживает изменения и прогоняет их через встроенные анализаторы. Затем формирует отчеты и отправляет их пользователю.

Учебный проект Хекслета: https://ru.hexlet.io/programs/rails-developer
Как это должно работать: https://files.hexlet.app/a/klff0i

## Установка

Чтобы запустить проект локально, выполните:

```bash
make setup
```

После этого откройте приложение в браузере:

```text
http://localhost:3000
```

## Использование

Github Quality — сервис для автоматической проверки качества кода в GitHub-репозиториях. Проверки выполняются асинхронно с помощью Active Job, поэтому пользователь может продолжать работу с приложением, пока задача выполняется в фоне.

### Неавторизованный пользователь

Неавторизованный пользователь может:

- открыть главную страницу приложения
- ознакомиться с возможностями сервиса
- авторизоваться через GitHub

### Авторизованный пользователь

После авторизации через GitHub пользователь может:

- просматривать доступные GitHub-репозитории
- добавлять репозитории в сервис
- запускать проверку выбранного репозитория
- просматривать состояние запущенной проверки
- видеть результаты завершённых проверок
- просматривать найденные ошибки и информацию о состоянии кодовой базы

Проверка репозитория запускается как асинхронная задача. После запуска пользователь сразу получает информацию о том, что задача принята, а её статус обновляется по мере выполнения.
